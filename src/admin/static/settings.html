Isolation Invariants (read-only)

The following isolation controls are hard refusals enforced by the container runtime and are NOT configurable through the portal. Attempting to set any of these via the API returns 400. To inspect the current posture, see the Isolation page.
NET_ADMIN / NET_RAW / SYS_ADMIN: always dropped
--privileged: always refused
docker.sock mount: always refused
Concurrent profiles: always refused (one profile at a time)
