Onboard: Claude Code

Claude requires an OAuth token obtained by running a command in your host terminal. The portal cannot run this command for you.
Step 1: Run this command in your host terminal (outside any container)
claude setup-token

The command opens a browser for OAuth authentication and prints CLAUDE_CODE_OAUTH_TOKEN=<value> to stdout when complete.

Step 2: Copy the token value from your terminal and paste it below

Onboard: OpenAI Codex

The portal uses API keys for Codex. Set either OPENAI_API_KEY or CODEX_API_KEY. Either key satisfies the credential gate.
Step 1: Obtain an API key

Go to platform.openai.com, sign in, and create an API key. Do not share the key.

Step 2: Paste the API key below

This sets OPENAI_API_KEY. You may also set CODEX_API_KEY via the Credentials page if your setup requires it.
