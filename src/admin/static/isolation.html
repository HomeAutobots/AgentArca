D5.4 Hard Refusals

The following conditions cannot be set via the control plane. They are structurally absent from every write surface. Any API attempt to enable them returns 400 and is audited.

ConditionStatus
NET_ADMIN on devcontainer Hard refusal: cannot be granted via control plane
NET_RAW on devcontainer Hard refusal: cannot be granted via control plane
SYS_ADMIN on devcontainer Hard refusal: cannot be granted via control plane
--privileged on any service Hard refusal: cannot be set via control plane
docker.sock mount Hard refusal: cannot be mounted via control plane
Concurrent profiles Hard refusal: only one profile at a time (invariant 9)
